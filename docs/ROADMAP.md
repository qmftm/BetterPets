## 지금까지 확정된 것

빌드하고 코드를 짜면서 **실제로 확인한** 것들입니다. 문서만 보고 정한 게 아니에요.

- **빌드가 통과합니다** — JDK 25로 BetterModel 3.4.1 API에 대해 실제 컴파일.
  단위 테스트 182개 통과, 컴파일 경고 0
- **캐리어 엔티티는 보이지 않는 `Mob`** — `ItemDisplay` 대신 고른 이유는 자체 히트박스가 있어서예요.
  모델에 히트박스 본(`b_`)이 없어도 우클릭이 먹힙니다
- **BetterModel API 격리** — `BetterModelRenderer` 가 그 API를 import 하는 유일한 파일입니다
- **탑승은 `ArmorStand` + Paper `Input`** — `allowFlight` 를 안 쓰므로 비행 권한이 샐 위험 자체가 없어요
- **선택적 연동은 리플렉션** — DiscordSRV·Floodgate 가 없어도 빌드되고 돌아갑니다.
  상속이 필요한 PlaceholderAPI 만 예외로 컴파일 의존(`provided`)을 겁니다

## 다음에 직접 확인할 것

코드로는 더 할 게 없고, **테스트 서버에서 눈으로 봐야 하는** 것들이에요.

1. **모델이 실제로 뜨는가** — `.bbmodel` 하나를 넣고 `/betterpets egg` → 우클릭 → `/pet summon` 순으로
2. **트래커 누수가 없는가** — `/betterpets debug` 의 세 숫자(활성 펫 / 캐리어 / 트래커)가 일치하는지
3. **추종 이동이 자연스러운가** — 계단·언덕에서 끊기지 않는지, 텔레포트 폴백이 과하지 않은지
4. **탑승·비행 조작감** — 벽 슬라이딩과 하차 안전 처리가 실제로 먹히는지
5. **Bedrock 변환** — 모델 하나로 GeyserModelEngine 파이프라인을 끝까지 통과시켜 보기
6. **연동이 실제로 붙는가** — `/betterpets debug` 의 연동 줄에서 상태 확인
7. **여러 마리 소환** — `max-active` 를 2 이상으로 두고, 한 마리에 탔을 때 나머지가 제자리에 남는지.
   부채꼴로 벌어져 서는지도 같이 보세요
8. **소환 자리** — 벽을 등지고 서서 소환했을 때 펫이 블록 안에 파묻히지 않는지
9. **언어 전환** — `language: en_us` 로 바꾸면 채팅뿐 아니라 **보관함과 아이템 로어까지**
   영어로 나오는지. 한동안 GUI 만 한국어로 남아 있었습니다
10. **알 로어** — 랜덤 알을 들었을 때 나올 수 있는 펫과 확률이 실제로 보이는지
11. **비행 애니메이션** — 나는 펫에 타면 `ride` 가 아니라 `fly` 가 재생되는지.
    모델에 `fly` 를 안 만든 펫은 `idle` 로 접히는지도 같이 보세요
12. **스니크 하차 뒤 추종** — 내린 뒤 펫이 그 자리에 굳지 않고 다시 따라오는지
13. **보관함에 오래 둔 펫** — 아기를 넣어두고 성장 시간을 넘긴 뒤 보관함을 열었을 때,
    성체가 되어 있고 알림이 오는지. 접속을 끊었다 다시 들어오는 경우도 같이
14. **보관함 정렬·보기** — 20마리쯤 채운 뒤 정렬과 보기를 바꿔가며,
    쪽 넘김이 어긋나지 않는지와 상세에서 돌아왔을 때 화면이 유지되는지
15. **월드 이동** — 네더 포털을 지나면 따라오던 펫이 같이 넘어와 모델까지 정상인지.
    (코드는 다른 월드면 즉시 텔레포트하지만, BetterModel 트래커가 월드 이동을
    견디는지는 확인된 적이 없다)
16. **남의 펫 클릭** — 다른 플레이어의 펫을 손에 아이템을 들고 우클릭했을 때
    아이템이 사라지지 않는지. 오프핸드로도 같이 확인
17. **알 쓰는 느낌** — 허공에 대고 우클릭해야 까지는 규칙이 실제로 답답하지 않은지.
    답답하면 "블록을 봐도 까지되 상자·화로만 양보"로 좁히는 방법이 있지만,
    그 판정(`isInteractable`)은 플랫폼이 deprecated 로 표시해 둔 것이라 서버에서
    직접 확인한 뒤에 판단한다
18. **모델이 없는 진화** — `next-stage` 가 가리키는 펫의 모델을 일부러 빼두고 먹여서,
    "모델을 못 붙였다"는 안내가 나오는지

전체 수동 체크리스트는 [DESIGN.md의 테스트 절](DESIGN.md#테스트)에 있습니다.

> **Bedrock 검증은 일찍 하는 게 좋습니다.** BetterModel 3.4.1 + GeyserModelEngine + MC 26.2 조합은
> 검증된 적이 없어요. 모델을 여러 개 만든 뒤에 안 되는 걸 알면 텍스처부터 다시 작업해야 합니다.
> 첫 모델이 자바에서 뜨자마자 그 하나로 Bedrock 변환을 시험해 보세요.
